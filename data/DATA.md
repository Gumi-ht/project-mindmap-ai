# Деректер сипаттамасы

Барлық деректерді команда өзі жасаған. Нақты адамдардың жеке деректері қолданылмайды.
**Лицензия:** команданың өз деректері, CC BY 4.0.

## 1. Тақырыптар — `topics.csv`

**Авторы:** Сұлтанбек Айзере

ICT1103 курсының 1–8 апталарындағы 8 тақырып және олардың арасындағы байланыстар.

| Баған | Сипаттамасы |
|---|---|
| topic_id | тақырып коды (T1–T8) |
| week | курс аптасы |
| name | тақырып атауы |
| prereq | осы тақырып сүйенетін базалық тақырыптар (`;` арқылы) |
| material_lecture | курс дәрісі |
| material_link | ашық қосымша материал (Wikipedia) |
| explanation | оқу бағытында көрсетілетін қысқа түсіндірме |

Тақырыптар байланысы: T1 → T2; T2 және T3 → T4; T3 → T5; T4 → T6; T6 → T7 және T8.

## 2. Сұрақтар — `questions.csv`

**Авторы:** [Аты-жөні, 1-қатысушы]

48 сұрақ, қазақ тілінде, әр тақырыпқа 6 сұрақтан:

- `use = test` — тестке арналған 32 сұрақ (әр тақырыпқа 4: 1 жеңіл, 2 орташа, 1 күрделі);
- `use = practice` — оқу бағытындағы өзін-өзі тексеруге арналған 16 сұрақ (әр тақырыпқа 2).

| Баған | Сипаттамасы |
|---|---|
| q_id | сұрақ коды (Q — тест, P — жаттығу) |
| topic_id | тақырып коды |
| difficulty | күрделілігі: 1 — жеңіл, 2 — орташа, 3 — күрделі |
| question | сұрақ мәтіні |
| a, b, c, d | жауап нұсқалары |
| correct | дұрыс жауап әрпі |
| use | test немесе practice |

Дұрыс жауаптар a, b, c, d орындарына тең бөлінген (тестте әр әріпке 8-ден), сондықтан бір әріпті таңдап, жоғары балл алу мүмкін емес. Кездейсоқ болжау ықтималдығы — 25%.
