# Деректер сипаттамасы

Барлық деректерді команда өзі жасаған. Нақты адамдардың жеке деректері қолданылмайды.
**Лицензия:** команданың өз деректері, CC BY 4.0.

## 1. Тақырыптар — `topics.csv`

**Авторы:** Сұлтанбек Айзере

ICT1103 курсының 1–8 апталарындағы 8 тақырып және олардың арасындағы байланыстар.

| Баған | Сипаттамасы |
|---|---|
| topic_id | тақырып коды (T1–T8) |
| week | курс аптасы |
| name | тақырып атауы |
| prereq | осы тақырып сүйенетін базалық тақырыптар (`;` арқылы) |
| material_lecture | курс дәрісі |
| material_link | ашық қосымша материал (Wikipedia) |
| explanation | оқу бағытында көрсетілетін қысқа түсіндірме |

Тақырыптар байланысы: T1 → T2; T2 және T3 → T4; T3 → T5; T4 → T6; T6 → T7 және T8.

## 2. Сұрақтар — `questions.csv`

**Авторы:** Сұлтанбек Айзере

48 сұрақ, қазақ тілінде, әр тақырыпқа 6 сұрақтан:

- `use = test` — тестке арналған 32 сұрақ (әр тақырыпқа 4: 1 жеңіл, 2 орташа, 1 күрделі);
- `use = practice` — оқу бағытындағы өзін-өзі тексеруге арналған 16 сұрақ (әр тақырыпқа 2).

| Баған | Сипаттамасы |
|---|---|
| q_id | сұрақ коды (Q — тест, P — жаттығу) |
| topic_id | тақырып коды |
| difficulty | күрделілігі: 1 — жеңіл, 2 — орташа, 3 — күрделі |
| question | сұрақ мәтіні |
| a, b, c, d | жауап нұсқалары |
| correct | дұрыс жауап әрпі |
| use | test немесе practice |

Дұрыс жауаптар a, b, c, d орындарына тең бөлінген (тестте әр әріпке 8-ден), сондықтан бір әріпті таңдап, жоғары балл алу мүмкін емес. Кездейсоқ болжау ықтималдығы — 25%.

## 3. Жасанды студенттер — `students.csv`, `true_levels.csv`

**Авторы:** Жұмай Назым

**Деректер жасанды (синтетикалық)**, `generate_data.py` скриптімен жасалған (`SEED = 42`, сондықтан қайта іске қосқанда нәтиже бірдей).

- 300 жасанды студент (S001–S300), әрқайсысы 32 тест сұрағына жауап берген — барлығы 9600 жауап.
- Әр студентке әр тақырып бойынша нақты деңгей кездейсоқ беріледі: 0 — білмейді, 1 — жартылай, 2 — біледі. Базалық тақырып әлсіз болса, тәуелді тақырып та жиі әлсіз болады.
- Деңгейге қарай жауап модельденеді: дұрыс жауап ықтималдығы 0,25 / 0,55 / 0,90, «сенімдімін» белгісі 0,20 / 0,50 / 0,85, орташа жауап уақыты 40 / 33 / 25 секунд (үлкен кездейсоқ ауытқумен).

| Файл | Бағандар |
|---|---|
| students.csv | student_id, q_id, topic_id, correct, confident, time_sec |
| true_levels.csv | student_id, topic_id, true_level — модель үшін дұрыс жауаптар |
| test_students.csv | тест бөлігіне түскен 60 студенттің тізімі (train.py жасайды) |

**Шектеу:** жауаптар біз ойлап тапқан ережелер бойынша жасалған, сондықтан нақты студенттердің мінез-құлқынан өзгеше болуы мүмкін. Сол себепті модель нақты студенттерде де тексеріледі (4-бөлім).

**Авторы:** Умаргазиева Зарина — 5–10 топтас студенттің келісімімен жиналады, аттары жоқ (R01, R02 кодтары).
