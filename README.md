# Білім картасы — білімдегі олқылықтарды анықтау және жеке оқу бағыты

ICT1103, QAIRU, 2026–2027. Екінші аралық бақылау, топтық жоба.

## Мәселе

Студент тест тапсырғанда тек жалпы балл алады, бірақ қай тақырыпты нашар түсінетінін және неден бастап оқу керегін білмейді. Мұғалім де топтың қай тақырыпта қиналатынын бірден көре алмайды. Көп жағдайда күрделі тақырыптағы қиындықтың себебі — базалық тақырыптағы олқылық.

## Пайдаланушы

- **Студент** — өзінің әлсіз тақырыптарын біліп, жеке оқу бағытын алады.
- **Мұғалім** — топтың қай тақырыптарды нашар түсінетінін көреді.

## Шешім

Веб-прототип:

1. Студент 8 тақырып бойынша 32 сұрақтан тұратын тест тапсырады, әр жауаптан кейін «сенімдімін» немесе «болжадым» деп белгілейді.
2. Жүйе әр тақырып бойынша деңгейді анықтайды: **біледі / жартылай біледі / білмейді**.
3. **Білім картасы** (майндмап) салынады: тақырыптар байланыстарымен, түсі — деңгейі (жасыл, сары, қызыл).
4. **Жеке оқу бағыты** құрылады: әлсіз тақырыптар дұрыс ретпен — алдымен базалық тақырып, содан кейін соған тәуелді тақырыптар.

Тізбек: тест жауаптары → тақырып бойынша белгілер → модель → деңгейлер → майндмап және оқу бағыты.

## Өзектілік: қай салаларда қолдануға болады

- **Мектептер мен университеттер** — мұғалім қайта түсіндіретін тақырыптарды көреді.
- **ҰБТ-ға дайындық** — оқушы уақытын білетін тақырыптарға жұмсамайды.
- **Онлайн-курстар** — әр оқушыға жеке бағыт.
- **Репетиторлар** — оқушының олқылықтарын бірінші сабақта анықтау.
- **Компаниялардағы оқыту** — қызметкерлердің біліктілігін тексеру.

## Пәнмен байланыс

- 4-апта: деректерді талдау және визуализация (белгілер, майндмап, жылу картасы).
- 6-апта: оқытушымен оқыту (деңгейді жіктеу).
- ПОН 5: машиналық оқытудың базалық әдісі — жіктеу.
- Тест сұрақтары ICT1103 курсының 1–8 апталарындағы тақырыптар бойынша құрастырылған.

## Әдіс

Әр тақырып бойынша 4 белгі есептеледі: дұрыс жауаптар үлесі (күрделілікті ескере отырып), «болжадым» үлесі, орташа жауап уақыты, базалық тақырып нәтижесі.

| Әдіс | Рөлі |
|---|---|
| Logistic Regression | **негізгі модель**, сайтта қолданылады |
| Decision Tree | салыстыру және түсіндіру үшін (`results/tree.png`) |
| Қарапайым ереже (ML-сіз): ≥70% — біледі, 40–70% — жартылай, <40% — білмейді | баламамен салыстыру |

Деректер **студенттер бойынша** бөлінді: 240 — оқыту, 60 — тест. Бір студенттің жауаптары тек бір бөлікте болады, сондықтан деректердің ағып кетуі жоқ.

GPU және ақылы сервистер қажет емес: модель кәдімгі компьютерде бірнеше секундта оқытылады.

## Іске қосу

1. Python 3.10 немесе жаңасын орнатыңыз.
2. Тәуелділіктерді орнатыңыз:
   ```
   pip install -r requirements.txt
   ```
3. Жасанды деректерді жасаңыз (міндетті емес, деректер репозиторийде бар):
   ```
   python generate_data.py
   ```
4. Модельді оқытыңыз:
   ```
   python train.py
   ```
5. Тексеру (метрикалар және қателер матрицасы):
   ```
   python evaluate.py
   ```
6. Сайтты іске қосыңыз:
   ```
   streamlit run app.py
   ```

Онлайн нұсқа: (https://project-mindmap-ai-d22mzuted8cwritsc5stek.streamlit.app/)
